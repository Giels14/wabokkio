# Paklijst vliegen met kinderen
*Wabokkio – Gezinsreizen, zonder gedoe*

**Documenten & geld**
- [ ] Paspoort/ID per gezinslid
- [ ] Boardingpassen
- [ ] Toestemmingsformulier (indien nodig)
- [ ] Reisverzekering + EHIC
- [ ] Boekingsbevestigingen
- [ ] Pinpas, creditcard, contant geld

**Handbagage baby**
- [ ] Luiers + reserve
- [ ] Doekjes + verschoonmatje
- [ ] 2x reservekleding
- [ ] Speen + reserve
- [ ] Melk/flesvoeding/potjes
- [ ] Draagzak
- [ ] Knuffel/doekje

**Handbagage peuter**
- [ ] Luiers of extra onderbroeken
- [ ] Reservekleding
- [ ] Drinkbeker (leeg)
- [ ] Kleine nieuwe speeltjes
- [ ] Rugzakje

**Handbagage grotere kinderen**
- [ ] Tablet + koptelefoon
- [ ] Boek/kleurboek
- [ ] Lege drinkfles
- [ ] Vest

**Snacks & drinken**
- [ ] Droge snacks + fruit
- [ ] Babyvoeding apart (uitgezonderd van 100 ml-regel in de EU)
- [ ] Iets om te drinken/kauwen bij opstijgen en landen

**Vermaak**
- [ ] Stickerboek, kleurspullen
- [ ] Ingepakte verrassingen
- [ ] Powerbank + kabels (handbagage)

**Kleding & comfort**
- [ ] Laagjes, makkelijke schoenen
- [ ] Sokken, nekkussen
- [ ] Reserveshirt voor jezelf

**Medicijnen** (overleg met apotheek/huisarts)
- [ ] Eigen medicijnen + bijsluiter
- [ ] Thermometer, pleisters
- [ ] Desinfectiegel, spuugzakjes

**Kinderwagen & autostoeltje** (check je airline)
- [ ] Buggy + hoes + label
- [ ] Autostoeltje of huurstoeltje

**Ruimbagage**
- [ ] Kleding per kind
- [ ] Zwemspullen + zwemluiers
- [ ] Toilettas, zonnebrand
- [ ] Slaapspullen, campingbedje

**Reisdag**
- [ ] Online inchecken
- [ ] Ruim op tijd
- [ ] Wc/verschonen voor instappen
- [ ] Naam + telefoonnummer bij jonge kinderen
