# Packing list for flying with kids
*Wabokkio – Family travel, made easy*

**Documents & money**
- [ ] Passport/ID for everyone
- [ ] Boarding passes
- [ ] Consent letter (if needed)
- [ ] Travel insurance + EHIC/GHIC
- [ ] Booking confirmations
- [ ] Cards and some cash

**Hand luggage: baby**
- [ ] Nappies + spares
- [ ] Wipes + changing mat
- [ ] 2 spare outfits
- [ ] Dummy + spare
- [ ] Milk/formula/pouches
- [ ] Baby carrier
- [ ] Comforter

**Hand luggage: toddler**
- [ ] Nappies or spare pants
- [ ] Spare clothes
- [ ] Sippy cup (empty)
- [ ] Small new toys
- [ ] Little backpack

**Hand luggage: older kids**
- [ ] Tablet + headphones
- [ ] Book/colouring book
- [ ] Empty water bottle
- [ ] Jumper

**Snacks & drinks**
- [ ] Dry snacks + fruit
- [ ] Baby food kept separate (exempt from 100 ml rule in the EU)
- [ ] Something to drink/chew for take-off and landing

**Entertainment**
- [ ] Sticker book, colouring things
- [ ] Wrapped surprises
- [ ] Power bank + cables (hand luggage)

**Clothing & comfort**
- [ ] Layers, slip-on shoes
- [ ] Socks, neck pillow
- [ ] Spare top for yourself

**Medicines** (check with pharmacist/GP)
- [ ] Own medicines + leaflet
- [ ] Thermometer, plasters
- [ ] Hand gel, sick bags

**Pushchair & car seat** (check with your airline)
- [ ] Buggy + cover + label
- [ ] Car seat or hire seat

**Hold luggage**
- [ ] Clothes per child
- [ ] Swimwear + swim nappies
- [ ] Wash bag, sun cream
- [ ] Sleep things, travel cot

**Travel day**
- [ ] Check in online
- [ ] Arrive in good time
- [ ] Toilet/nappy change before boarding
- [ ] Name + phone number on young kids
